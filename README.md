# Vehicle Information System in Java

## Overview
This project demonstrates the use of:
- Interfaces
- Inheritance
- Polymorphism
- Exception Handling
- Object-Oriented Programming Concepts in Java

The system allows users to:
- Create Cars
- Create Motorcycles
- Create Trucks
- Store vehicle details
- Display vehicle information

- Java
